## ECMAScript 2025

### Iterator Helpers
Methods like `.map()`, `.filter()`, `.take()`, `.drop()` are now available directly on iterators with **lazy evaluation** — no intermediate arrays created.

```js
// ❌ Old: creates new arrays at each step
const result = array
  .map(x => x * 2)
  .filter(x => x > 10)
  .slice(0, 3);

// ✅ New: lazy, memory-efficient
const result = Iterator.from(array)
  .map(x => x * 2)
  .filter(x => x > 10)
  .take(3)
  .toArray();
```

> Works on anything iterable: arrays, sets, maps, generators.

### Set Methods
New methods for comparing two Sets:

```js
const youKnow  = new Set(["JS", "Python", "CSS", "SQL"]);
const jobNeeds = new Set(["JS", "TypeScript", "Python"]);

youKnow.intersection(jobNeeds);        // → Set {"JS", "Python"}
youKnow.union(jobNeeds);               // → Set {"JS", "Python", "CSS", "SQL", "TypeScript"}
jobNeeds.difference(youKnow);          // → Set {"TypeScript"}  (skill gaps!)
youKnow.symmetricDifference(jobNeeds); // → Set {"CSS", "SQL", "TypeScript"}
jobNeeds.isSubsetOf(youKnow);          // → false
youKnow.isSupersetOf(jobNeeds);        // → false
youKnow.isDisjointFrom(jobNeeds);      // → false
```

### RegExp Updates

**`RegExp.escape()`** — safely escapes user input for use in a regex (after a 15-year wait!):

```js
// ❌ Before: breaks if user types $9, (off!), etc.
const badRe  = new RegExp(userInput, "g");

// ✅ ES2025
const goodRe = new RegExp(RegExp.escape(userInput), "g");
```

**Inline flags per group** — mix case sensitivity within one regex:

```js
/(?i:[a-z.]+)@(?-i:[A-Z]+)\.(?i:com|org)/
// ^^^^^ case-insensitive   ^^^^^ case-SENSITIVE
```

### Promise.try()
Unified error handling for functions that might throw sync *or* reject async:

```js
// ❌ Before: two separate error paths
let p;
try { p = loadUser(id); } catch (e) { handleError(e); }
p?.catch(e => handleError(e));

// ✅ ES2025: one .catch() handles both
Promise.try(() => loadUser(id))
  .then(user => render(user))
  .catch(err => showError(err));
```

### Import Attributes
Import JSON or CSS directly using the `with` keyword:

```js
import data   from "./file.json"      with { type: 'json' }
import styles from "./component.css"  with { type: 'css'  }
```

> ⚠️ JSON import caveat: if it fails, it takes the whole module graph down. Prefer dynamic `import()` with a try/catch, or just use `fetch()` for better garbage collection.

CSS imports work great with Web Components:

```js
import sheet from './styles.css' with { type: 'css' };

class MyComponent extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' }).adoptedStyleSheets = [sheet];
  }
}
```

## ECMAScript 2026

### Temporal API ⭐
**Dates and times in JavaScript are finally good.** No more Moment.js needed.

```js
// Get current time in any timezone
const now = Temporal.Now.zonedDateTimeISO("America/New_York");
console.log(now.toLocaleString());

// Correct month arithmetic (old Date API gave Mar 03 instead of Feb 28!)
const jan31 = Temporal.PlainDate.from("2026-01-31");
jan31.add({ months: 1 }).toString(); // → "2026-02-28" ✅

// Correct duration comparison
Temporal.Duration.compare(
  Temporal.Duration.from({ hours: 25 }),
  Temporal.Duration.from({ days: 1 }),
  { relativeTo: Temporal.Now.plainDateISO() }
); // → 1  (25h > 1 day) ✅
```

> Safari support is in Technical Preview — full cross-browser soon.

### Explicit Resource Management (`using` keyword)
Guarantees cleanup when a variable goes out of scope, even if an error is thrown:

```js
async function saveData() {
  await using file = new FileHandle("output.txt");
  await file.write("hello world");
  // file is auto-flushed + closed here, even on error
}

// Multiple resources → AsyncDisposableStack
async function runJob() {
  await using stack = new AsyncDisposableStack();
  const db      = stack.use(await openDatabase());
  const file    = stack.use(new FileHandle("output.txt"));
  const tmpDir  = stack.defer(async () => removeTempDir("/tmp/job"));
  // All three cleaned up in reverse order on exit
}
```

### Array.fromAsync
Collects values from an async iterator into a plain array:

```js
async function* fetchNumbers() {
  yield 1;
  await delay(100);
  yield 2;
  await delay(100);
  yield 3;
}

const numbers = await Array.fromAsync(fetchNumbers());
// → [1, 2, 3]
```

---

### Iterator.concat
Lazily chains multiple iterators — saves memory if you bail early:

```js
for (const item of Iterator.concat(page1, page2, page3)) {
  process(item); // streams lazily, no upfront array allocation
}
```

## Frameworks

### React (v19.2)
- **RSC (React Server Components)** — run components on the server, ship less JS to client
- **Server Actions** — call server-side functions directly (great for forms)
- **React Compiler** — auto-applies `useMemo`/`useCallback` optimizations at build time
- ⚠️ RSC had back-to-back critical security vulnerabilities in 2025 — stay updated

### Vue (v3.5 stable, v3.6 alpha)
- **Vapor Mode** (opt-in, v3.6) — fine-grained reactivity, performance comparable to Solid/Svelte 5
- Nuxt went v4.0, acquired by Vercel
- Pinia v3 — dropped Vue 2 support

### Svelte (v5)
- **Runes API** — new reactivity model, more fine-grained and efficient
- Part of Vercel ecosystem alongside SvelteKit
